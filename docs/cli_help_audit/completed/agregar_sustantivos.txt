Usage: biorag agregar_sustantivos <concept> "keyword1,keyword2"

Summary:
Assign topic keywords in permanent or working memory.

What is it for?
Assign or update topic keywords on an existing permanent or working memory to improve
retrieval. This does not establish which version of a fact is current.

`sustantivos clave` (key nouns: the core topic of a memory).

Before you start:
referenced nodes must already exist.

Changes memory or state. To test on a disposable copy, use: BIORAG_PATH=/path/copy.db
biorag agregar_sustantivos ...

Options:
--sustantivos-clave "a,b"  Alternative to the positional keyword list.
    --sustantivos           Alias of --sustantivos-clave.
    Aliases: agregar-sustantivos, asignar_sustantivos, asignar-sustantivos.

Examples:
  biorag agregar_sustantivos servicio_puerto_actual "service,port"

Expected output:
The updated keyword list for the selected concept.
Runtime messages retain their existing language (often Spanish); JSON keys are unchanged.

See also:
  biorag buscar --help
  biorag estado --help
