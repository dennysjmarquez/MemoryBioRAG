usage: biorag recovery [-h] --receipt RECEIPT [--stage]

Summary:
After an update failure, inspect the backup referenced by its update receipt.

What is it for?
After an update failure, inspect the backup referenced by its update receipt. With
--stage, preserve a snapshot of the present and restore the old backup to a separate
file. This never overwrites live memory or activates an older program version.

Before you start:
The receipt selects the source database. BIORAG_PATH does not override it. Keep the receipt and backup; verify code and data compatibility before using a staged copy.

options:
  -h, --help         show this help message and exit
  --receipt RECEIPT  JSON update receipt reported on failure, stored in
                     update-receipts beside the database
  --stage            Authorize recovery copies; never replace the current
                     database

Examples:
  biorag recovery --receipt /path/update-receipts/receipt.json
  biorag recovery --receipt /path/update-receipts/receipt.json --stage

Expected output:
JSON recovery plan; --stage reports separate snapshots and live_database_unchanged. No
live recovery was executed.
Runtime messages retain their existing language (often Spanish); JSON keys are unchanged.

See also:
  biorag update --help
