biorag asociar <concept_a> <concept_b>
    Create a bidirectional association between related concepts.
    Options:
    No additional options.

Why use it? Connect related concepts for associative retrieval. An association does not
mean one fact replaces another.

Before you start: referenced nodes must already exist.

Changes memory or state. To test on a disposable copy, use: BIORAG_PATH=/path/copy.db
biorag asociar ...

Examples:
  biorag asociar service_configuration service_deployment
