biorag buscar <query> [options]
    Search permanent memory using textual, semantic and associative signals.
    Options:
    --sustantivos-clave "a,b"  Topic keywords; alias: --sustantivos.
    --deep                  Include dormant memories and wake retrieved dormant nodes.
    --todos                 Request up to 100 results.
    --tokens "root1,root2"   Search stemmed tokens instead of a phrase.
    --modo strict|relaxed   Token matching; default: relaxed.
    --frase                 Explicit phrase search (the default route).
    --pagina N              Results page, starting at 1.
    --cat TYPE              Filter by category.
    --completo              Show full content rather than a preview.
    --asociados             Show associated concepts and topic keywords.

Why use it? Retrieve a permanent memory before saving a duplicate. Newly saved working
memories become searchable after biorag sueno. Results are not proof that a fact is
current.

Side effects: --deep wakes retrieved dormant nodes and changes their weight. Search may
also write search logs and learning state; it is not a read-only audit.

Changes memory or state. To test on a disposable copy, use: BIORAG_PATH=/path/copy.db
biorag buscar ...

Examples:
  biorag buscar "service configuration" --sustantivos-clave "service,config"
  biorag buscar service --completo --asociados
