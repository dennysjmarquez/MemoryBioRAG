usage: biorag correcciones confirmar [-h] [--db DB] --id ID --digest DIGEST
                                     --request-id REQUEST_ID

Why use it? After reviewing and deciding the replacement is correct, approve it with the
reviewed digest and a request ID for duplicate-free retries. History is preserved; the
command does not establish that the evidence is true.

Database: --db overrides BIORAG_PATH. Use an existing disposable copy.

options:
  -h, --help            show this help message and exit
  --db DB               Existing database; defaults to BIORAG_PATH or the
                        canonical path
  --id ID               Stable proposal identifier
  --digest DIGEST       Digest returned by revisar; do not invent one
  --request-id REQUEST_ID
                        Confirmation request ID; reuse for an identical retry

Examples:
  Use an existing test copy; replace the illustrative paths and node IDs.
  UNIX dates are illustrative; never invent actual effective dates.
  Replace DIGEST_DE_LA_REVISION with the digest returned by revisar.
  biorag correcciones confirmar --db /ruta/copia_prueba.db \
    --id cambio-puerto-001 --digest DIGEST_DE_LA_REVISION --request-id aprobacion-001
